# proto-plugins

[Proto](https://moonrepo.dev/proto) plugins for:
- [Prism](https://stoplight.io/open-source/prism)
  ```
  proto plugin add prism "https://raw.githubusercontent.com/vortechsa/proto-plugins/master/prism/plugin.toml"
  proto install prism
  ```

- [SOPS](https://getsops.io/)
  ```
  proto plugin add spectral "https://raw.githubusercontent.com/vortechsa/proto-plugins/master/sops/plugin.toml"
  proto install sops
  ```

- [Spectral](https://stoplight.io/open-source/spectral)
  ```
  proto plugin add spectral "https://raw.githubusercontent.com/vortechsa/proto-plugins/master/spectral/plugin.toml"
  proto install spectral
  ```
