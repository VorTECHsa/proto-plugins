# proto-plugins

[Proto](https://moonrepo.dev/proto) plugins for:
- [Prism](https://stoplight.io/open-source/prism)
  ```
  proto plugin add prism "https://raw.githubusercontent.com/vortechsa/proto-plugins/main/prism/plugin.toml"
  proto install prism
  ```
- [Spectral](https://stoplight.io/open-source/spectral)
  ```
  proto plugin add spectral "https://raw.githubusercontent.com/vortechsa/proto-plugins/main/spectral/plugin.toml"
  proto install spectral
  ```
